# Рилс с кинетической типографикой

Два шаблона (см. их README):
- `reels/anthropic-academy/` — **основной, для длинных роликов (30–60 с)**: каждая сцена — функция
  `B[i](t, L)`, старты сцен (`cues`) берутся прямо из пауз озвучки, анимация сама растягивается под длину фразы.
- `reels/kinetic-claude/` — короткий (~20 с): анимация в своём темпе + якоря-time-warp (`anchors`).

Новый ролик = копия шаблона в
`reels/<slug>/` с новым текстом, новой озвучкой и новыми таймингами. Ничего не генерируется внешними
видеосервисами: анимация — HTML + GSAP, рендер — Chromium покадрово, звук — синтез в numpy, сведение — ffmpeg.

Общайся с пользователем по-русски, коротко и без жаргона: он часто работает с телефона.

**Предпочтения пользователя (по умолчанию):**
- Ролик быстрый и динамичный: паузы в озвучке ужимать до ~0.1 с (`tighten.py`), речь ускорять ~×1.08.
- Звуки — **не на каждый переход**: только акцентные склейки (~каждая 2–3-я: смена темы, нумерация 01/02/03,
  «бесплатно», финал), и звук — **порыв ветра** (`wind()` в `sound.py`), без ударов, щелчков и лазеров.
- Музыка — тёмный бит 128 BPM, приглушается под голос, короткий провал перед кульминацией.

## 1. Разбор референса (если прислали видео)

```bash
ffprobe -v error -show_entries format=duration:stream=width,height -of compact ref.mp4
ffmpeg -v error -i ref.mp4 -vf "fps=1/3,scale=360:-1,tile=5x2" -frames:v 4 grid_%02d.jpg   # затем Read
```

Выпиши: палитру, шрифты (жирный широкий / узкий / курсив), приёмы движения, ритм (сколько секунд на сцену).
Чужие бренды, логотипы и упоминания из референса не переносить, если пользователь не просил.

## 2. Текст озвучки

Напиши текст из коротких фраз (1 фраза = 1 сцена, 0.5–2 с каждая), ~12 фраз на 15–20 с.
Отдай его пользователю для ElevenLabs (сайт/приложение на телефоне → «Сгенерировать» → скачать mp3 →
прислать в чат) или для записи своим голосом. Ключ API в чат не просить: если пользователь хочет,
чтобы ты сам ходил в ElevenLabs, ключ кладётся в секреты окружения, а `api.elevenlabs.io` — в разрешённые домены.

## 3. Сцены — `index.html`

Скопируй шаблон: `cp -r reels/anthropic-academy reels/<slug>` (без `node_modules`, `reel_final.mp4`, `voice.mp3`).
Каждая сцена — `<div class="sc …" id="sN">`; фон: `.red`, `.blk` (чёрный с красным свечением), `.wht`.
Шрифты: `.unb` (Unbounded 900 — удары), `.osw` (Oswald — узкий капс), `.pfd` (Playfair italic — акцент).
Класс `.split` режет текст на буквы `.ch` для побуквенной анимации. Ширина текста подгоняется автоматически (≤ 940 px).

Готовые приёмы в таймлайне (бери и переставляй):
- **Удар**: `fromTo(scale:3→1, blur 30→0, expo.out)` + `shake(sel, t)`
- **Влёт/вылет с моушн-блюром**: `x/y ±900…1500` + `filter: blur(30px)`, `power3.in` на выход
- **Буквы падают**: `.ch` со `stagger:.035`, `scaleY:3→1`, `back.out`
- **Жидкие буквы**: `rotation/skewX` + `elastic.out`, затем волна `yoyo`
- **Печать по буквам**: `stagger:.1`, `scale:1.8→1`; **зачёркивание/подчёркивание**: `.line` `scaleX:0→1`
- **Лазер**: точка `.dot` + `.line` слева направо, затем `scaleY:500` как переход
- **Лучи скорости**: `#s8lines`; **рассыпающиеся кейфреймы**: `#s9tl .kf`; **мишень**: SVG `stroke-dashoffset`
- **Вспышка**: `flash(t, opacity)`; **переход-шторка**: `clipPath: inset(50% 0 50% 0)`
- `show(id, t, len)` включает сцену на отрезок. В конце должны быть `window.DURATION`, `window.seek`, `window.READY`.

Анимацию пиши в «своём» темпе (~1.2–2 с на сцену) — под голос её подгонят якоря на шаге 5.

## 4. Проверка кадров

```bash
cd reels/<slug> && npm i && node render.js --snap 0.5,2,4,6,8,10,12,14,16,18
```
Склей снимки в контакт-лист (ffmpeg `xstack`) и посмотри через Read: текст не обрезан, нет пустых/белых кадров.

## 5. Подгонка под голос — `timing.json`

**Шаблон anthropic-academy (cues):**

```bash
mv voice.mp3 voice_raw.mp3
<python с numpy> -I tighten.py voice_raw.mp3 voice.mp3 0.1 1.08   # ужать паузы, ускорить; печатает фразы
python3 cues.py                                                   # cues и end в timing.json
```
Сопоставь фразы с текстом по длительности (отрезки 0.3–0.6 с — обычно одно слово: «Anthropic», «Сейчас»,
«Сайт») и впиши в `timing.json` → `scene_segments` номер фразы, с которой стартует каждая сцена; `accents` —
номера сцен, где звучит ветер. `cues.py` ставит `cues[i]` = начало фразы − `lead` (0.06 с), `end` = конец речи
+ `tail` (1.6 с). Ударные моменты внутри сцены — доли `L` в `B[i]`: прикинь, на какой доле сцены звучит слово,
по длинам фраз из `segments.json`, и подгони. Звук считается от `cues` сам.

**Шаблон kinetic-claude (anchors):**

```bash
./pauses.sh voice.mp3          # N  начало – конец  для каждой фразы
```
Число фраз должно совпасть с текстом; если нет — меняй порог (`./pauses.sh voice.mp3 -30 0.2`).
Якоря `anchors`: `[время фразы в ролике (на 0.05–0.1 с раньше начала речи), время начала сцены в index.html]`.
Для ударных слов внутри фразы добавляй отдельный якорь. Последний якорь — конец ролика
(речь + ~2–3 с на финальный логотип). Сжатие сцены сильнее чем в ~0.4 раза выглядит суетливо — тогда
сократи анимацию сцены в `index.html`, а не только якоря.

## 6. Рендер, звук, сведение

```bash
node render.js                         # silent.mp4
PYTHON=<python с numpy> bash mix.sh     # reel_final.mp4
```
В `sound.py` (anthropic-academy) SFX — только `wind()` на сценах из `timing.json → accents`, пик порыва
ровно на склейке; на кульминациях (`big`) порыв длиннее и громче. Другие синтезаторы (`impact`, `whoosh`,
`tick`, `laser`, `riser`) остались в файле — используй, только если пользователь попросит.
Музыка: `BPM`, `roots` (бас), `silent` (провал перед кульминацией), `END`. `DUR` = длина ролика + запас.

Баланс: голос главный. Проверяй громкость стемов:
`ffmpeg -i sfx.wav -af volume=0.27,ebur128 -f null - 2>&1 | grep -A1 Integrated` — SFX и музыка должны быть
на 5–8 LU тише голоса. Регулируй `SFX_VOL` / `MUSIC_VOL`. Итог нормализуется до −14 LUFS.

Сам звук ты не слышишь — скажи пользователю, что проверял тайминги и уровни, и попроси оценить на слух.

## 7. Сдача

Отправь `reel_final.mp4` через SendUserFile (`display: render`). Предложи правки: громкость музыки/эффектов,
свой трек (mp3 → вместо `music.wav` в `mix.sh`), длинную версию. Сохрани проект в репозиторий и запушь.

## Грабли

- `window.seek` **не должен возвращать** таймлайн (`t=>{tl.seek(t,false);}`) — иначе `page.evaluate`
  пытается сериализовать объект GSAP и рендер виснет без ошибки.
- Строй таймлайн и автоподгонку ширины **после** `document.fonts.load(...)` всех шрифтов (см. шаблон
  anthropic-academy) — иначе ширина меряется по запасному шрифту и края слов обрезаются.
- Перед полным рендером всегда делай `--snap` по серединам сцен и смотри контакт-лист.
- Полный рендер 50 с ≈ 10 мин — запускай в фоне (`node render.js > render.log 2>&1 &`) и параллельно готовь звук.
- `pkill -f render.js` убивает и твой же шелл (строка есть в его команде) — не используй.

## Окружение

- Chromium: Playwright ищет сам; иначе `CHROMIUM=/opt/pw-browsers/chromium…`. `playwright install` не запускать.
- numpy ставь в venv в scratchpad: `python3 -m venv venv && venv/bin/pip install numpy`.
- Модели распознавания речи (whisper) из HuggingFace могут быть недоступны — тайминги бери из `pauses.sh`.
