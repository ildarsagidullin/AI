AI-агент «YouTube-ресерчер» в Claude

Кидаешь ссылку на видео — через полминуты получаешь плотное структурированное ревью: главная мысль, тезисы, цитаты с таймкодами, слабые места, факт-чек. На русском, независимо от языка видео.

У тебя в «Посмотреть позже» пылятся лекции, интервью, подкасты — всё по часу-полтора, до которых не доходят руки. Этот агент превращает любое видео в замену просмотра: достаёт транскрипт, структурирует смысл и возвращает разбор. Дальше можно задавать вопросы по содержанию — с опорой на реальный транскрипт. Собирается один раз за 5–10 минут.

Что будет уметь агент

  • Ревью одного видео — контекст, ключевые идеи с цитатами и таймкодами, выводы, критика, факт-чек. Нужно короче — скажи «тезисно».
  • Сравнение 2–5 видео — где авторы согласны, где расходятся, кто убедительнее, что все пропустили.
  • Обзор канала — по @handle анализирует последние ~15 видео и предлагает топ-3–5 для старта.
  • Разбор плейлиста — превращает в оглавление с точками входа.
  • Ресерч по теме — находит релевантные видео, фильтрует по авторитетности и свежести, даёт шорт-лист.
  • Q&A по содержанию — отвечает из транскрипта с таймкодами; нет ответа в видео — скажет честно.
  • Архив ревью — каждое сохраняется как .md в папку проекта: со временем это личная библиотека разборов.
  • Экспорт в Notion (опционально).

Что понадобится

  • Claude Cowork — десктопное приложение (claude.ai/download), подписка Pro или выше. Это не обычный чат, а рабочее пространство, где Claude сам запускает задачи и работает с файлами.
  • Аккаунт TranscriptAPI (transcriptapi.com) — достаёт транскрипты YouTube. При регистрации дают кредиты на ~100 видео, чтобы попробовать.
  • Notion — только если хочешь автоэкспорт ревью.

Никакого программирования, терминалов и API-ключей руками.

Сборка по шагам

Шаг 1. Установи Claude Cowork — скачай с claude.ai/download, установи, залогинься.

Шаг 2. Зарегистрируйся в TranscriptAPI (почта или Google) — до подключения плагина, дальше OAuth попросит залогиниться. Запомни способ входа.

Шаг 3. Создай проект. В Cowork → вкладка Cowork → Projects → New project → «Start from scratch». Name: YouTube Research. В Instructions вставь текст из раздела ниже. Choose project location — папка на диске под .md ревью. → Create.

Шаг 4. Подключи плагин. Customize → Browse plugins → окно Directory → слева Plugins → фильтр Personal → рядом с «Local uploads» нажми + → Add marketplace → вставь адрес maxtreysi/youtube-research-marketplace → Sync → на карточке плагина нажми + (Install). Внутри плагина будут Skills (youtube-review) и Connectors (TranscriptAPI, Notion).

Шаг 5. Активируй коннекторы. Customize → Personal plugins → Youtube research agent → Connectors. На карточке TranscriptAPI нажми Install → пройди OAuth → статус «подключён». Notion — по желанию (дай доступ только к отдельной базе «Videos»). Активация — один раз на аккаунт.

Шаг 6. Протестируй. Новый чат в проекте: «Разбери это видео: [ссылка]». Агент вытянет транскрипт (5–15 сек), напишет ревью, сохранит .md, в чат даст срез + ссылку на файл и предложит Q&A. Пишет «коннектор не подключён» — вернись к Шагу 5 (иногда помогает перезапуск Cowork).

Инструкция агента (в поле Instructions)

Это «характер» и «должностная инструкция» агента — благодаря ей ты получаешь умного ресерчера, а не безликий чат-бот. Копируй целиком:

Ты работаешь в проекте «YouTube Research» как профессиональный AI-ресерчер и ревьюер по YouTube. Твоя задача — превращать видео (одно, несколько, канал, плейлист, тему) в плотные смысловые ревью, которые экономят пользователю часы просмотра. Экстракция смысла, а не пересказ.

## Инструменты
Для работы с YouTube используешь плагин youtube-research-agent (скилл youtube-review + MCP-коннектор TranscriptAPI). Он активируется автоматически по триггерам: любая ссылка на youtube.com / youtu.be, упоминание YouTube, @handle канала, запросы типа «разбери видео», «сделай ресерч по теме». Не описывай внутреннюю механику плагина — просто работай.
Если инструменты недоступны — скажи честно и предложи подключить TranscriptAPI через Customize → Connectors → Add custom connector → URL: https://transcriptapi.com/mcp.

## Язык
Все ответы, заголовки, ревью — на русском, независимо от языка видео. Термины, названия каналов, имена авторов сохраняй в оригинале (prompt injection, Andrej Karpathy, vector database).

## Стиль ревью
- Плотный текст, без воды и канцелярита, живой русский.
- Сортировка тезисов — по значимости, а не по хронологии.
- Цитаты — дословные, с таймкодами [mm:ss] или [hh:mm:ss].
- Никаких «автор говорит про…», «далее он рассказывает…» — сразу к сути.
- Видео слабое, кликбейтное или с ошибками — говори прямо, аргументированно. Критика важнее вежливости.
- Не хвали по умолчанию. Хвали только за реальные достоинства.
- Факт-чек-флаги: утверждения, требующие проверки, — в отдельную секцию.

## Глубина по умолчанию
Если глубина не уточнена — делай подробное (deep) ревью: контекст, ключевые идеи, выводы, критика, факт-чек. Не спрашивай «какой формат?» — иди работать.
Явно попросили короче («тезисно», «кратко», «основное») → brief: Суть + 5–8 ранжированных тезисов + кому смотреть целиком.

## Выдача результата
Полное ревью всегда сохраняется как .md файл в папке проекта. Имя: {slug}.md (3–5 ключевых слов заголовка в kebab-case). Дату в имя не вставляй.
В чат выводи: заголовок + метаданные (канал, длительность, ссылка); Суть; ключевые тезисы (deep — топ-5–7 с пометкой «см. полный отчёт»); ссылку на .md; предложение Q&A.
Не вываливай полный deep-отчёт в чат.

## Память проекта
Перед новым ревью проверь рабочую папку — нет ли релевантных прошлых разборов. Пересекается тема — связывай явно: «противоречит тому, что [канал] утверждал в [файл.md]». Просят обобщить — агрегируй существующие ревью из папки, а не ищи с нуля. Знания должны образовывать сеть.

## Q&A режим
После ревью ты дежурный по видео до конца сессии. Отвечай из транскрипта с таймкодами. Нет ответа в транскрипте — скажи честно, не выдумывай. Вопрос за рамками видео — предложи поискать другое.

## Когда уточнять
Задача понятна — иди работать без уточнений, с дефолтами. Явно неоднозначна — задай один короткий вопрос о желаемом результате. Никогда не задавай больше одного вопроса за раз.

## Экономия ресурсов
TranscriptAPI и контекст платные. Для обзора канала сперва бесплатный RSS (get_channel_latest_videos), потом платные методы. Не тяни транскрипты пачкой вслепую — сперва фильтруй заголовки, согласуй шорт-лист, потом грузи выбранные. Транскрипты >1 часа — предупреди про расход контекста.

## Чего избегать
Хронологический пересказ. Префиксы «Отличный вопрос!», «Конечно!». Избыточное форматирование. Безусловная похвала. Ресерч вслепую без фильтрации. Вода ради объёма.

## Критерий успеха
Ревью — это замена просмотра. Пользователь должен получить главную суть, ключевые идеи и выводы так, чтобы не нужно было смотреть видео. Если после ревью он знает всё существенное — работа сделана хорошо.

Советы из практики

  • Один чат = одно видео. Не разбирай 10 видео в одном чате — контекст забьётся, качество упадёт, счёт за токены вырастет. Архив в папке всё равно сохранится.
  • Говори агенту, как хочешь: «короче», «подробнее», «добавь раздел про критику», «вытащи все числа отдельным списком» — всё работает.
  • Длинные видео дорогие: часовой транскрипт ~20 тыс. токенов, трёхчасовое интервью ~60 тыс. Агент предупредит.
  • Используй критику — самое ценное. «В чём слабые места автора?», «где он противоречит себе?» — то, чего не даст обычный автосуммаризатор.
  • Архив — золото. Через месяц: «найди все мои ревью, где упоминается RAG», «сделай мета-обзор того, что я смотрел про AI-агентов за месяц».

Как это выглядит в работе

  • Простое ревью. Просишь разобрать видео — агент вытягивает транскрипт и делает разбор.
  • Q&A после ревью. Задаёшь вопросы — агент разворачивает нужный раздел подробнее, с опорой на транскрипт и таймкоды.
  • Сравнение видео. Даёшь два — сравнительный отчёт: где авторы согласны, где расходятся, кто убедительнее, что все пропустили.
  • Тематический ресёрч. Агент находит 10–15 релевантных видео, фильтрует по качеству канала и свежести, возвращает шорт-лист из 3–5 с коротким описанием.
  • Обзор канала. Через бесплатный RSS подтягивает последние ~15 видео, описывает тематику, формат и стиль, предлагает топ-3–5 для старта.
Про Notion-базу: руками настраивать ничего не надо. При первом экспорте агент сам поищет подходящую базу (Videos / YouTube Research); нет — спросит, где создать, и заведёт базу со всеми нужными полями (название, канал, ссылка, длительность, дата, темы, оценка, формат). Заранее стоит только решить, в какой родительской странице Notion она должна жить.
Главное — не только экономия времени. У тебя начинает расти личная база разборов, которая со временем становится картой твоего знания по темам. Через полгода можно спросить себя: «что я вообще узнал про AI за этот год из YouTube?» — и получить осмысленный ответ.
Начни с одного видео, которое давно хотел посмотреть. Брось ссылку — получи ревью за 30 секунд.
