Что такое вайбкодинг

Способ создавать цифровые продукты с помощью ИИ: ты описываешь словами, что хочешь, а ИИ генерирует код, дизайн и структуру за тебя. Термин придумал Андрей Карпаты — ты не пишешь код, а задаёшь вайб, направление.

Но это не магия, а навык — простой. Нужно уметь формулировать запросы, понимать, из чего состоит сайт, направлять ИИ и видеть, что вышло хорошо, а что доработать. Учится это за дни, а не месяцы.

Что реально можно собрать

Для бизнеса: лендинги, сайты-визитки, интернет-магазины, внутренние инструменты (дашборды, калькуляторы, трекеры), MVP для стартапов. Для себя: портфолио, сайт-поздравление, свадебное приглашение, квиз/игра в подарок, блог. Для заработка: сайты на заказ, лендинги под инфопродукты, автоматизация рутины. Это не «поиграться» — рабочий инструмент, закрывающий задачи, за которые раньше платили много денег.

И это не только про бизнес. Знакомый перед 14 февраля за пару часов собрал сайт-поздравление для девушки — с анимациями, личными фото и своим текстом. Он не дизайнер, просто описал, что хочет (и даже попросил ИИ придумать идеи). Реакция: «лучший подарок из всех, что я дарил». Раньше между «я хочу» и «я сделал» стоял барьер: навыки, люди, деньги. Сейчас его нет — хочешь сюрприз, портфолио или запуск проекта, просто делаешь.

Пошагово: твой первый сайт

Шаг 1. Claude Code. Инструмент от Anthropic, позволяет общаться с ИИ и создавать проекты целиком. Зарегистрируйся на claude.ai и оформи подписку Claude Pro ($20/мес) — минимальный тариф с полной мощностью.

Шаг 2. VS Code. Бесплатный редактор кода (code.visualstudio.com) — просто место, где лежит проект и виден результат. Установка стандартная. Создай папку (например, reset-fitness), в VS Code: File → Open Folder → выбери её.

Шаг 3. Расширение Claude в VS Code. Extensions (иконка квадратиков) → поиск «Claude» → Install → войди в аккаунт. Теперь общаешься с ИИ прямо в редакторе, и он создаёт файлы на месте.

Шаг 4. Подготовь запрос — самый важный шаг (см. раздел ниже).

Шаг 5. Отправь и получи первую версию. Claude сгенерирует HTML/CSS в файл index.html. Открой его: правая кнопка → «Открыть с помощью» → браузер. Первая версия не идеальна — это нормально: скажи, что поправить («заголовок крупнее», «фон тёмный», «кнопку ярче»). 2–3 итерации — и готово.

Как составить хороший запрос

Чем точнее опишешь — тем лучше результат. ❌ «Сделай мне сайт, красивый». ✅ Вот так:

Сделай лендинг для фитнес-клуба «RESET» в Москве. Красные и тёмные тона, жёсткий стиль.
На странице: заголовок с фото логотипа, блок «о нас» (2 предложения), меню (3 варианта оплаты абонемента), галерея из 4 фото, кнопка «Связаться с нами» со ссылкой на Telegram.
Адаптивная вёрстка под телефоны. Без сложных анимаций.

Ответь на 4 вопроса: что это (лендинг/визитка/магазин)? для кого? что должно быть на странице (блоки, кнопки, тексты)? какой стиль (можно дать ссылку на понравившийся сайт)?

Сложно описать — попроси Claude помочь: «Я хочу сделать сайт-визитку для [кто ты / чем занимаешься]. Помоги составить подробное описание для генерации сайта: задай мне нужные вопросы». Он задаст 5–7 вопросов и соберёт идеальный промпт сам.

GitHub и публикация

Шаг 6. GitHub. Бесплатное хранилище для проекта (нужно и для публикации, и чтобы код не потерялся). Зарегистрируйся на github.com, создай репозиторий (New repository), загрузи файлы. Лайфхак: Claude сделает это сам — попроси:

Инициализируй git-репозиторий, создай коммит и загрузи проект на GitHub.

Claude часто просит разрешение на операции — как правило, ничего критичного, можно смело разрешать (Enter).

Шаг 7. Опубликуй сайт.

  • GitHub Pages (бесплатно): Настройки репозитория → Pages → ветка main → Save. Через пару минут обнови страницу — появится ссылка на живой сайт вида username.github.io/имя-репозитория/.
  • TimeWeb (почти бесплатно): App Platform → подключи GitHub-репозиторий → импортируй → сайт опубликуется автоматически, получишь бесплатный домен (можно подключить свой .ru/.com).

Бонус: Skills — секретное оружие для качества

Skills — готовые наборы инструкций, которые говорят ИИ, как делать работу качественно (best practices вёрстки, паттерны, структура кода). Как если бы ты нанял опытного разработчика вместо стажёра.

Пример: перед тем как просить сайт, загрузи скилл по фронтенд-дизайну — скопируй его содержимое и отправь Claude перед основным запросом. Официальный скилл frontend-design от Anthropic: github.com/anthropics/claude-code/.../frontend-design/SKILL.md. Результат становится заметно современнее: шрифты, дизайн, анимации.

Честный FAQ

«Я далёк от технологий». Вайбкодинг для тебя и создан — пишешь обычным языком, не на Python. Умеешь описать, чего хочешь, — готов.

«Это только для простых страничек?» Нет — собирают полноценные веб-приложения, дашборды, платформы. Но для старта начни с простого: лендинг, визитка, поздравление.

«Сколько стоит?» Единственная обязательная трата — Claude Pro $20/мес. VS Code, GitHub, GitHub Pages — бесплатно.

«А это точно будет выглядеть нормально?» Напишешь «сделай сайт» без контекста — выйдет средненько. Потратишь 10–15 минут на хороший запрос — будет выглядеть как от дизайнера. Освоишь референсы и итерации — конкурирует с профессиональными сайтами. ИИ уже «знает» тысячи паттернов хорошего дизайна — ему нужно правильное направление от тебя.

Между «я хочу» и «я сделал» больше нет барьера. Открывай VS Code.
