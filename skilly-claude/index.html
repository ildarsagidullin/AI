1. Что такое скилл и зачем он нужен

Скилл (Agent Skill) — это папка с инструкциями, которую Claude подхватывает, когда она нужна. Внутри — файл SKILL.md (что делать и когда), а рядом по желанию скрипты, шаблоны, примеры и справочники.

Представь папку-методичку для нового сотрудника: «вот как мы оформляем документы», «вот как разбираем заявки», «вот наш стиль текста». Claude открывает эту методичку ровно в тот момент, когда взялся за подходящую задачу — и делает по ней.

Чем скилл отличается от обычного промпта

Промпт ты пишешь заново каждый раз. Скилл создаёшь один раз — и дальше Claude сам его достаёт, когда задача совпадает. Не надо копировать одну и ту же простыню инструкций в каждый чат.

Почему это не перегружает Claude

Хитрость в том, что скиллы грузятся послойно (это называют «progressive disclosure» — постепенное раскрытие). Claude держит в голове только название и короткое описание каждого скилла — это копейки. А полную инструкцию читает, только когда скилл реально понадобился.

СлойКогда грузитсяЦена
Название + описаниевсегда~100 токенов на скилл
Инструкция (тело SKILL.md)когда скилл сработалобычно до 5к токенов
Файлы и скриптытолько если понадобились0, пока не открыты

Поэтому можно держать десятки скиллов сразу — и это почти не ест контекст. Claude берёт нужный, остальные лежат и ждут.

Что скиллы дают на практике

  • Специализация. Claude становится экспертом под твою задачу — по твоим правилам и стилю.
  • Ноль повторов. Настроил один раз — работает во всех чатах автоматически.
  • Повторяемый результат. Одинаково хорошо каждый раз, а не «как повезёт».
  • Комбинируются. Несколько скиллов складываются в сложные многошаговые процессы.

2. Кто их делает и почему они лежат на GitHub

Кто делает скиллы

  • Anthropic (создатели Claude) — официальные скиллы: работа с Word/Excel/PowerPoint/PDF, конструктор скиллов, сборка MCP.
  • Крупные компании — под свои продукты: Vercel (React/Next.js), Supabase (Postgres), Google, OpenAI, Firecrawl, Sentry.
  • Сообщество — тысячи людей делают скиллы под маркетинг, контент, YouTube, автоматизацию и что угодно ещё.

Почему именно GitHub

Скилл — это по сути папка с текстовыми файлами. А GitHub — стандартное место, где такие штуки удобно хранить, обновлять и раздавать. Причин три:

  • Раздача. Дал ссылку — и любой поставил себе. Не нужен ни магазин, ни установщик.
  • Версии. Автор правит скилл — видно, что менялось, и можно откатиться. Ты всегда берёшь свежую версию.
  • Открытость. Скилл — это инструкции и код, которые получат доступ к твоим файлам. На GitHub его видно насквозь: можно прочитать перед установкой и убедиться, что там нет дичи. Про безопасность — в разделе 10.
Скиллы работают по открытому стандарту Agent Skills (agentskills.io) — один и тот же скилл понимают Claude, Cursor, Codex, Gemini CLI и другие. То есть это не «фишка только Claude», а общий формат.

Это первое, что путает новичков. Скиллы можно ставить в двух разных местах, и они не связаны между собой.

Скиллы не синхронизируются между приложением и Claude Code. Загрузил в claude.ai — в Claude Code его нет, и наоборот. В каждое место ставишь отдельно.

4. Установка в приложение Claude (claude.ai)

Шаг 1. Включи «выполнение кода»

Без этого скиллов вообще не будет видно. Заходишь в Настройки → Возможности (Settings → Capabilities) и включаешь тумблер «Выполнение кода и создание файлов» (Code execution and file creation).

На Team/Enterprise это должен сначала включить владелец рабочего пространства в настройках организации. Если раздел скиллов серый или его нет — почти всегда дело именно в невключённом выполнении кода.

Шаг 2. Открой список скиллов

Идёшь в Настроить → Скиллы (Customize → Skills). Здесь список: сверху — готовые скиллы Anthropic (Word, Excel, PowerPoint, PDF), их можно включать тумблером. Они и так срабатывают сами, когда ты просишь сделать документ.

Шаг 3. Загрузи свой скилл (ZIP)

Чтобы добавить скилл со стороны, его надо запаковать в ZIP. Дальше на странице скиллов жмёшь «+» → Создать скилл → Загрузить скилл (Upload a skill) и выбираешь ZIP-файл.

Главное про ZIP: внутри архива должна лежать папка скилла с файлом SKILL.md внутри, а не голые файлы и не лишняя обёртка сверху. Имя папки должно совпадать с именем скилла. Если структура кривая — загрузка не пройдёт.

Если качаешь скилл с GitHub: жмёшь Code → Download ZIP, при необходимости распаковываешь и запаковываешь именно папку нужного скилла (ту, где лежит SKILL.md), а не весь репозиторий целиком.

Загрузка своих скиллов доступна на планах Pro, Max, Team и Enterprise при включённом выполнении кода. Скиллы в claude.ai персональные — у каждого свои, между сотрудниками не расшариваются.

5. Установка в Claude Code

Тут проще: скилл — это просто папка на компе. Есть три способа поставить, от ручного до «одной командой».

Куда вообще кладутся скиллы

ТипПутьГде работает
Личный~/.claude/skills/имя/SKILL.mdво всех твоих проектах
Проектный.claude/skills/имя/SKILL.mdтолько в этом проекте (можно закоммитить в репо для команды)
На Windows ~ — это твоя папка пользователя, то есть C:\Users\Имя\.claude\skills\.

Способ 1. Вручную — положить папку

Скачал скилл с GitHub → положил папку скилла (в которой SKILL.md) в ~/.claude/skills/. Всё. Claude Code подхватывает изменения на лету, без перезапуска.

Способ 2. Через плагины и маркетплейс

В Claude Code встроен магазин плагинов. Пишешь в терминале команду /plugin — открывается браузер плагинов, вкладка Discover со списком. Выбираешь — Enter — ставится.

По умолчанию там только официальный маркетплейс Anthropic. Чтобы добавить чужой (например, из GitHub-репозитория) — командой:

/plugin marketplace add владелец/репозиторий

При установке Claude Code спросит масштаб: User — для всех твоих проектов (~/.claude/skills/), Project — только для текущего (.claude/skills/). Обычно выбираешь User, если это не командная настройка под конкретный проект.

Способ 3. Одной командой (npx skills)

Многие скиллы из подборок ставятся одной строкой — прямо из папки проекта в терминале:

npx skills add владелец/репозиторий

Например, npx skills add google-labs-code/stitch-skills. Команда сама скачает скилл и положит его куда надо. У каждого скилла в его репозитории обычно написана точная команда установки — бери оттуда.

6. Как создать свой скилл

Создать скилл проще, чем кажется. Минимум — это один файл SKILL.md. Всё остальное по желанию.

Из чего состоит SKILL.md

Файл делится на две части: шапка в тройных дефисах (YAML-фронтматтер) — где сказано, когда скилл применять; и тело — сами инструкции. Вот минимальный рабочий пример:

---
name: razbor-pisem
description: Разбирает входящие письма и готовит черновики ответов в моём стиле. Использовать, когда прошу разобрать почту, ответить на письма или навести порядок во входящих.
---

# Разбор писем

Когда я прошу разобрать почту:
1. Раздели письма на важные, обычные и спам.
2. По важным подготовь черновики ответов в деловом, но живом тоне.
3. Ничего не отправляй сам — только черновики.
4. В конце дай короткий список, что требует моего решения.

Два обязательных поля в шапке

ПолеЧто этоПравила
nameимя скилла (и команда для вызова)до 64 символов, только строчные буквы, цифры и дефисы; без слов «claude» и «anthropic»
descriptionчто скилл делает и когда его применятьдо 1024 символов, обязательно не пустое
Описание решает всё. Именно по нему Claude понимает, что пора достать твой скилл. Пиши в нём и что скилл делает, и когда его включать — с конкретными фразами-триггерами («когда прошу…», «если речь про…»). Размытое описание = скилл не сработает сам никогда.

Где создать файл

В Claude Code — просто создай папку и файл: ~/.claude/skills/razbor-pisem/SKILL.md. Claude Code увидит его сразу, без перезапуска.

Ленивый способ — скилл, который делает скиллы

Не хочешь возиться руками — есть официальный skill-creator от Anthropic. Он берёт у тебя интервью, сам подбирает настройки и пишет готовый SKILL.md в нужную папку. Просто попроси Claude Code создать скилл под твою задачу — и он проведёт тебя за руку.

Держи тело скилла коротким — до 500 строк. Большие справочники выноси в отдельные файлы рядом и ссылайся на них из SKILL.md: Claude откроет их, только когда понадобятся.

7. Как протестировать и отредактировать

Как проверить, что скилл работает

В Claude Code два пути:

  • Пусть сработает сам. Напиши обычный запрос, который подходит под описание («разбери мою почту»). Если описание нормальное — Claude сам подтянет скилл.
  • Вызови вручную. Набери /имя-скилла (для примера выше — /razbor-pisem). Скилл запустится принудительно.

Посмотреть все установленные скиллы можно командой /skills — там видно, что откуда пришло (личное, проект, плагин).

Как отредактировать

Просто открой SKILL.md в любом редакторе и правь текст. Claude Code ловит изменения на лету — сохранил файл, и новая версия работает в той же сессии. Перезапускать ничего не надо.

В приложении claude.ai по-другому: там скилл живёт в облаке. Чтобы обновить — правишь файлы, снова пакуешь в ZIP и загружаешь заново (либо удаляешь старый и грузишь новый).

8. Как часто обновлять скиллы

Короткий ответ: по расписанию — не надо. Скиллы сами не обновляются, и гоняться за апдейтами каждый день смысла нет. Обновляй в двух случаях:

  • Автор выпустил новую версию — исправил ошибки, добавил возможности.
  • Изменилось то, с чем скилл работает — обновился сервис, поменялся его интерфейс или API, и старая инструкция стала неточной.

Как обновлять — по способу установки

Как ставилКак обновить
Скачал папку с GitHubскачай свежую версию и замени папку (или git pull, если клонировал)
Через npx skills addзапусти ту же команду ещё раз — подтянет свежую
Через плагин /pluginобновление приходит, когда автор поднимает версию; обновляешь из меню /plugin
Загрузил ZIP в claude.aiскачай новую версию и загрузи заново
Практика: если сильно зависишь от скилла — раз в месяц загляни в его репозиторий, посмотри, не вышло ли обновление. Свои личные скиллы правишь тогда, когда сам замечаешь, что Claude стал делать не то.

9. Как удалить или отключить скилл

Не зашёл скилл — убираешь за секунду. Способ зависит от того, куда ставил.

В приложении Claude (claude.ai)

Отключить: в Настроить → Скиллы просто выключи тумблер у скилла — он останется, но не будет срабатывать.

Удалить совсем: кликни на скилл → кнопка «...» рядом с тумблером → Удалить → подтверди.

В Claude Code

Что за скиллКак убрать
Личный или проектныйудали его папку: ~/.claude/skills/имя/ или .claude/skills/имя/
Из плагинаотключи или снеси плагин: /plugin uninstall имя-плагина@маркетплейс
Хочешь оставить, но чтобы не срабатывал самдобавь в шапку SKILL.md строку disable-model-invocation: true — тогда только ты вызываешь его вручную
Claude Code уберёт скилл из текущей сессии сразу, как удалишь папку — перезапуск не нужен.

10. Безопасность: чему нельзя доверять

Важный раздел, не проскакивай. Скилл даёт Claude новые инструкции и код, а в Claude Code — ещё и доступ к твоим файлам. Плохой скилл может увести данные или наделать дел.

Ставь скиллы только из источников, которым доверяешь: свои собственные или от Anthropic и известных компаний. Чужой скилл из ниоткуда — сначала открой и прочитай.
  • Читай перед установкой. На GitHub всё видно: открой SKILL.md и скрипты, глянь, нет ли странных сетевых запросов или доступа к тому, что задаче не нужно.
  • Особо осторожно со скиллами, которые лезут в интернет — подтягивают данные с внешних адресов. Туда может прилететь чужая вредная инструкция.
  • Относись как к установке программы. Скилл — это код. Не запускал бы левую программу — не ставь и левый скилл, особенно там, где есть доступ к важным данным.

11. С чего начать

Не пытайся освоить всё сразу. Сделай так:

  1. Реши, где работаешь — в приложении Claude или в Claude Code. Ставь туда.
  2. Поставь один готовый скилл под свою реальную задачу и проверь его в деле.
  3. Когда поймёшь логику — собери свой первый скилл из одного SKILL.md. Даже маленький.

Скиллы — это не про «технично». Это про то, чтобы перестать каждый раз объяснять Claude одно и то же и переложить повторяющуюся работу на систему.

P.S. Начни с одного скилла под задачу, которую делаешь чаще всего. Настроил один раз — экономишь время каждый день. Это выгоднее, чем сто сохранённых видео «про ИИ», которые ты так и не открыл.
